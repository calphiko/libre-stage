libreStage – User Manual

libreStage ist eine selbst-gehostete Webanwendung zur internen Verwaltung von Bands und Musikensembles. Sie vereint Gig-Planung, Setlist-Editor, Song-Datenbank, Proben-Organisation, Abstimmungen und einen Live-Modus für Auftritte in einer einzigen Plattform.

Note

Screenshot folgt – bitte docs/manual/_static/screenshots/overview.png ablegen.

Key Features

  • Gig-Verwaltung – Konzerte anlegen, Setlists erstellen, GEMA-Export und PDF-Druck

  • Setlist-Editor – Drag & Drop, automatische Zeitberechnung, Sänger-Farb-Kodierung

  • Live Mode – Song navigation and rating during a performance

  • Song-Datenbank – Vollständiges Repertoire mit Metadaten, Status-Workflow und Statistiken

  • Proben-Planung – Proben anlegen, Aufgaben verteilen, Fortschritt verfolgen

  • Polls – Opinion surveys, date finding and gig request votes

  • Benutzer & Rollen – Rollenbasierte Zugangskontrolle (admin / editor / musician)
